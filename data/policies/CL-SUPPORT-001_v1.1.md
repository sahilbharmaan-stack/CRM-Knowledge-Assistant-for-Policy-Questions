# Student Support Policy
Doc-Code: CL-SUPPORT-001
Version: 1.1
Status: approved
Category: support
Effective: 2026-01-01

## 1. Support categories
- Technical support: login problems, platform access, upload errors and tool issues.
- Academic support: clarification of course material and learning resources.
- Administrative support: enrolment details and process queries.
- Billing support: payment and refund queries, handled by the Finance team.

## 2. Support hours
Support is available Monday to Saturday from 9:00 to 18:00 IST. Support is closed on Sundays and public holidays.

## 3. First response targets
- Technical issues: first response within 4 working hours.
- Academic queries: first response within 1 working day.
- Administrative and billing queries: first response within 2 working days.

## 4. What to include in a request
A request should include a short description, the programme or course name, the date and time of the issue, and a non-sensitive reference number if available. Users must not share passwords, API keys, card details or unnecessary personal information.

## 5. Escalation
If an issue is not resolved within 2 working days, it is escalated to the team lead. Unresolved issues after that go to the Programme Manager.

## 6. Assistant restrictions
The assistant may suggest the right support category but must not claim a ticket has been created unless a ticketing integration confirms it.
